# Data

No patient data is committed to this repository. `python -m fl_engine.data.download` fetches the files into
`data/raw/` (gitignored) and writes `data/raw/MANIFEST.json` with SHA-256 hashes, so runs can be checked against
the exact bytes used.

## 1. UCI Heart Disease (primary, natural federation)

- Source: https://archive.ics.uci.edu/dataset/45/heart+disease (archive `heart+disease.zip`, files `processed.*.data`)
- Licence: **CC BY 4.0** (as listed on the UCI page).
- Citation: Janosi, A., Steinbrunn, W., Pfisterer, M., & Detrano, R. (1989). *Heart Disease* [Dataset].
  UCI Machine Learning Repository. https://doi.org/10.24432/C52P4X
- Sites (used as 4 FL clients): Cleveland Clinic Foundation (303), Hungarian Institute of Cardiology, Budapest (294),
  University Hospital Zurich/Basel, Switzerland (123), V.A. Medical Center, Long Beach (200).

### Datasheet
- **Collection:** patients referred for coronary angiography, 1981–1988. The 14 "processed" attributes are a subset of 76.
- **Target:** `num` (0–4, angiographic diameter narrowing >50 % in any major vessel). We use `y = 1 if num > 0`.
  This is *prevalent angiographic CAD*, not the paper's *4-year incident MI/HF*. The tasks differ.
- **Known biases:** referral (all patients were already suspected of heart disease), so prevalence is far higher than in the
  general population. Strong site shift: positives are 46 % (Cleveland), 36 % (Hungarian), 94 % (Switzerland), 75 % (VA).
  Mostly male (~79 %). Historical data, so it does not reflect current treatment.
- **Missing values** (fraction, after treating `chol = 0` and `trestbps = 0` as missing):

| site | trestbps | chol | fbs | slope | ca | thal |
|---|---|---|---|---|---|---|
| cleveland | 0.00 | 0.00 | 0.00 | 0.00 | 0.01 | 0.01 |
| hungarian | 0.00 | 0.08 | 0.03 | 0.65 | 0.99 | 0.90 |
| switzerland | 0.02 | 1.00 | 0.61 | 0.14 | 0.96 | 0.42 |
| va_long_beach | 0.28 | 0.28 | 0.04 | 0.51 | 0.99 | 0.83 |

  (generated by `fl_engine.data.loaders.summarize`; see PROGRESS.md for the command output)

## 2. Cardiovascular Disease dataset, 70,000 records (scale experiments)

- Source: https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset (file `cardio_train.csv`,
  `;`-separated). It downloads through the public Kaggle API endpoint without login.
- Licence: **listed as "Unknown" on Kaggle** (checked via the Kaggle API on 2026-10-22). We therefore do **not**
  redistribute it, only download it at run time. Anyone reusing results should confirm terms with the uploader.
- Citation: Ulianova, S. (2019). *Cardiovascular Disease dataset*. Kaggle.
- **Collection:** stated by the uploader to be from medical examinations. The provenance, country and period are not documented,
  which is a significant limitation.
- **Target:** `cardio` (presence of cardiovascular disease, as defined by the uploader). Prevalence 0.495.
- **Features:** age (days → years), sex, height, weight, BMI (derived), systolic/diastolic BP, cholesterol (1–3),
  glucose (1–3), smoking, alcohol, physical activity. There are no missing values, but there are many implausible entries.
- **Cleaning rule** (`load_cardio70k(clean=True)`): keep 80 ≤ ap_hi ≤ 250, 40 ≤ ap_lo ≤ 160, ap_hi > ap_lo,
  120 ≤ height ≤ 220 cm, 30 ≤ weight ≤ 250 kg. 70,000 → 68,608 rows.
- **Federation:** none exists in the data. Sites are simulated with Dirichlet label/feature skew, which is an explicit limitation.
- **Low-prevalence variant:** positives are subsampled (fixed seed) to 6.4 % prevalence to mimic the base paper's imbalance.

## 3. Preprocessing rules (no leakage)
Imputation, scaling and feature selection are fitted **only on the training fold of each site** (federated setting)
or on the pooled training fold (centralised setting), then applied to validation/test data. The schema is
harmonised across sites (same columns, same encodings). Categorical `cp` and `restecg` are one-hot encoded with a
fixed category list.
